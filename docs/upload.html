上載相片

在手機或 iPad 上選相片，上載到 GitHub 之後，儀表板一兩分鐘內就會換上新相片。

1. 授權

需要一個 GitHub 令牌，只授予 jungold785/ipad 這個倉庫的「內容」讀寫權限。令牌只保存在這部裝置的 瀏覽器裡，不會上傳，也不會寫進倉庫。

建立令牌

如何建立令牌（兩分鐘）
  1. 開啟 GitHub 的「細部個人存取權杖」頁面，命名 ipad-photos。
  2. Repository access 選 Only select repositories，勾選 jungold785/ipad。
  3. Repository permissions 把 Contents 設成 Read and write。
  4. 按 Generate token，複製那串以 github_pat_ 開頭的字串。
  5. 貼到上面的欄位並按「儲存」。

令牌只存在本機。想全部撤銷，到 GitHub 的 Settings → Developer settings 刪除它即可。
